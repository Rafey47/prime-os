About Prime OS
Prime OS is a web-based desktop model made with HTML, CSS, and vanilla JavaScript.

  Live Demo: rafey47.github.io/prime-os
  
What is this?

Prime OS was created as a side project to explore how closely we could replicate a real desktop environment using a web technology. Instead of getting involved with low-level programming, I wanted to concentrate on the front-end operations and create an interactive desktop environment right inside the web browser.

Features:

1 Completely web-based (operates inside the tab)
2 Interactive windows that you can start and close
3 Modern-looking desktop design 
4 Good responsive design
5 Requires no installation or other dependencies
6 Technical Stack
7 HTML5 and CSS3 used for design
8 Uses JavaScript for window management and all UI functionality
9 Uses GitHub Pages for hosting purposes
10 Project Structure is simple 

prime-os/
 index.html
 style.css
 script.js
 README.md
 
Getting it running locally
To check out the code and run the project in your desktop, you should clone the repo and run it:

git clone https://github.com/Rafey47/prime-os.git

After that just open the file named index.html in your browser.
No npm install, no build tools, just open and go.
